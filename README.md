# Bookshelf App

A web based bookshelf application that allows users to manage their reading list using JavaScript and Local Storage.

## Features

- Add new books
- Search books by title
- Edit book information
- Delete books
- Move books between completed and unfinished shelves
- Persistent data using Local Storage

## Technologies

- HTML5
- CSS3
- JavaScript (ES6)
- Web Storage API

## How to Run

1. Clone this repository
2. Open `index.html` in your browser
